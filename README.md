# Claude Architect Exam Prep

Study notes and resources for preparing for the **Claude Certified Architect** exam.

This repository contains Markdown files only, for now.

## Goals

- Build a structured set of notes covering the exam topics
- Collect key concepts, patterns, and best practices for designing solutions with Claude
- Keep practice questions and review checklists in one place
